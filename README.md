# BookOasis Karaoke Singer

TJ / 금영 노래방 번호 검색 + 예약 대기열 + Fair Rotation + YouTube/로컬 MR 자동 탐색을 제공하는 BookOasis 플러그인입니다.

## 핵심 기능

### 곡 목록
- TJ / 금영 카탈로그 동기화 (증분 동기화 기본, 필요 시 "전체 동기화"로 모든 번호대를 처음부터 다시 확인)
- 매일 새벽 자동 동기화 (백그라운드 스케줄러, 수동 동기화와 충돌 없이 동작)
- 118,000곡 이상 규모에서도 빠른 목록/검색 (파일 변경 감지 캐시, 검색어 사전 인덱싱)
- 제목 기준 가나다·ABC·번호 순 정렬, TJ/금영 구분 없이 통합 정렬
- `songs_seed.json` 번들 시드 - 새로 설치하는 인스턴스가 동기화 없이 바로 전체 목록을 쓸 수 있음 ("시드 내보내기" 버튼으로 생성). BookOasis가 DB 테이블은 미리 만들어두고 데이터만 비어 있는 신규 설치에서도, 그 빈 테이블을 감지해서 백그라운드로 자동 채운다(기존 데이터가 있으면 절대 건드리지 않음). 전체 카탈로그(10만곡 이상)는 TJ/금영이 차트처럼 한 번에 내려주는 API가 없어서, 최초 수집은 이 시드 방식(또는 "TJ/금영 동기화" 수동 버튼)으로 하고, 그 이후 최신곡 반영은 매일 새벽 4시 자동 동기화가 담당한다. **시드 파일 자체는 이 zip을 다시 배포할 때 갱신되는 고정 스냅샷**이며(2026-09-11 기준 113,727곡: TJ 56,244 · 금영 57,483), 설치 이후의 최신곡은 매일 새벽 4시 자동 동기화가 알아서 채워나간다 - 신규 사용자가 수동으로 시드를 갱신할 필요는 없다.
- TJ/금영 카탈로그에 없는 곡을 직접 추가하는 "곡 추가" 기능 (제목/가수/유튜브 URL)

### 검색·탐색
- 가나다/ABC/번호 카테고리, TJ/금영 브랜드 필터, 텍스트 검색
- 즐겨찾기 - 곡별 별표 토글(브라우저 로컬 저장), 좌측 메뉴에서 즐겨찾기 목록만 보기
- 인기차트 - 재생 기록을 집계해 많이 재생된 곡 순으로 표시
- **TJ 공식 차트** - tjmedia.com의 TOP100/HOT100을 그대로 가져와 좌측 메뉴에서 볼 수 있습니다. 카탈로그에 동기화되지 않은 곡도 표시되며, 그런 곡은 "카탈로그 미동기화"로 표시되지만 예약/MR 재생은 그대로 가능합니다(제목·가수 기반 검색이라 카탈로그 등록 여부와 무관하게 동작). 6시간 캐시로 TJ 서버에 매 요청마다 부담을 주지 않습니다.
- **금영 공식 차트** - kysing.kr의 인기차트(일간/주간/월간/연간)를 그대로 가져옵니다. TJ 차트와 동일하게 카탈로그 미동기화 여부 표시, 6시간 캐시, 예약/MR 재생을 지원합니다.
- 재생 기록 - 예약 재생·미리듣기 이력, 클릭하면 바로 다시 재생
- 인기차트/재생기록/즐겨찾기/TJ 공식차트 모두 팝업이 아닌 메인 목록 영역에 인라인으로 표시되며, "전체 목록으로" 버튼으로 돌아갈 수 있음

### 예약 · 재생
- 검색 → 예약 → Fair Rotation(예약자별 공평 순환) → MR 탐색 → 재생 → 완료 → 다음곡
- MR 없이 곡만 바로 미리듣기("MR" 버튼) 가능, 예약 대기열과 별도로 동작
- 재생 진행바 클릭으로 탐색(seek), ±10초 버튼, 0.75x~1.25x 배속 조절 (유튜브·로컬 파일 공통)
- TV 모드 - 실제 재생 화면이 제자리에서 전체화면으로 확장(영상 재로드 없이 끊김 없음)

### MR 탐색
1. `karaoke_queue.sqlite3`의 MR 캐시 (대체 후보 목록 포함)
2. 곡별로 수동 지정한 유튜브 URL (검색보다 항상 우선, 각 곡의 🔗 버튼으로 지정/해제)
3. `MR_LOCAL_PATHS`에 설정한 로컬 MR 파일
4. `yt-dlp`의 YouTube 검색 (검색어 8종 다양화 + 채널 다양성 재정렬, 금영 채널 우선)
5. `YOUTUBE_API_KEY`가 설정되어 있으면 YouTube Data API fallback (`videoEmbeddable=true`로 필터링)

임베드 차단(101/150/153) 발생 시 자동으로 다음 후보로 전환하고, 해당 영상을 전역 차단 목록에 등록해 이후 어떤 곡에서도 다시 추천되지 않습니다.

### 마이크 이펙트
- 노래방 에코 효과 (에코 양·지연·볼륨 조절)
- 스피커 환경 하울링 방지: 브라우저 내장 에코 캔슬레이션 + 피드백량 상한 캡 + 실시간 하울링 감지·자동 노치 필터·순간 덕킹
- 내 목소리 녹음 및 즉시 재생/다운로드

## 권장 yt-dlp 설치

BookOasis 컨테이너 내부에서 공식 Linux binary를 PATH에 설치하는 것을 권장합니다.

```bash
mkdir -p /usr/local/bin
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
chmod 755 /usr/local/bin/yt-dlp
yt-dlp --version
```

또는 플러그인 폴더를 영구 마운트하고 있다면 포함된 `install_ytdlp.sh`를 실행하면 `karaoke_singer/bin/yt-dlp`에 설치할 수 있습니다. Resolver가 이 경로를 자동으로 확인합니다.

컨테이너 재생성 시 `/usr/local/bin/yt-dlp`가 사라지는 환경이라면 호스트 경로를 bind mount하거나 BookOasis의 영구 bin 경로를 `YTDLP_PATH`에 지정하세요.

현재 yt-dlp의 YouTube 검색 prefix는 `ytsearch:`입니다. Resolver는 검색 단계에서 `--flat-playlist` + `--print`를 사용하므로 검색 결과만 빠르게 수집하고 실제 미디어 다운로드는 하지 않습니다.

## 플러그인 설정

| 키 | 설명 | 기본값 |
|---|---|---|
| `YOUTUBE_API_KEY` | 마지막 fallback용. 없어도 yt-dlp 검색은 사용할 수 있습니다. | (없음) |
| `YTDLP_PATH` | yt-dlp 실행 파일 경로. | `yt-dlp` |
| `MR_LOCAL_PATHS` | 로컬 MR 검색 루트. `;`로 여러 경로 지정. | (없음) |
| `MR_LOCAL_PUBLIC_MAPS` | 로컬 파일을 브라우저가 접근할 URL로 매핑. 예: `/media/karaoke=/media/karaoke` | (없음) |
| `MR_YTDLP_RESULTS` | 검색 후보 수. | 8 |
| `MR_SEARCH_TIMEOUT` | yt-dlp 검색 제한시간(초). | 12 |

## 데이터 저장

- `data/songs.json` - 동기화된 곡 목록 (mtime 기반 캐시)
- `data/karaoke_queue.sqlite3` - 예약 대기열, 재생 기록, MR 캐시, 차단 영상 목록, 수동 지정 MR (기본 저널 모드로 동작하여 zip 업데이트 시 부속 파일 충돌이 없음)
- `songs_seed.json` - 플러그인 폴더에 함께 배포되는 번들 시드 (개인정보·예약 정보 없음, 곡 목록만 포함)

기존 `karaoke_queue.sqlite3`와 `plugin_karaoke_songs` 데이터는 업데이트 후에도 유지됩니다.
